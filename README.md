# Mario Kart 3D - KartRider Grand Prix Edition 🏎️💨

웹 브라우저에서 바로 즐기는 3D 카트 레이싱 게임 (카트라이더 스타일 주행 물리 엔진 탑재).

🌐 **온라인 플레이 (GitHub Pages)**: [https://gilsy02.github.io/Kart-game-Claude-code/](https://gilsy02.github.io/Kart-game-Claude-code/)

> Claude Code로 개발하는 버전입니다. Antigravity 버전은 [Kart-game-Antigravity](https://github.com/gilsy02/Kart-game-Antigravity)에 있습니다.

---

## 🎮 게임 조작법 (Controls)

| 키 입력 | 동작 | 설명 |
| :--- | :--- | :--- |
| **`[↑]` / `[W]`** | 가속 (Accelerate) | 일반 주행 최고 속도 **150 km/h** |
| **`[↓]` / `[S]`** | 브레이크 / 후진 | 감속 및 정지 후 후진 |
| **`[←][→]` / `[A][D]`** | 핸들 조향 (Steer) | 속도에 맞춘 정밀 조향 |
| **`[Shift]`** | **카트라이더 드리프트** | 차체 22° 틸트 슬라이드, 드리프트 게이지 충전 |
| **`[Shift] 해제`** | **순간 부스터 (Mini-Turbo)** | 코너 탈출 즉시 **200 km/h** 급가속 (0.85초) |
| **`[Space]` / `[Ctrl]`** | **N2O 부스터 점화** | 듀얼 배기구 화염 방출, **최고 250 km/h** 폭풍 질주 (3.2초) |
| **`[M]`** | 사운드 음소거/켜기 | 엔진 사운드, 드리프트 스키드음 토글 |

## ✨ 핵심 기능 (Features)

1. **Kenney Car-Kit 3D 모델 & 고유 컬러링**
   - 4종 독창적 카트 도장 (Player: 일렉트릭 사이언, AI1: 플레임 레드, AI2: 토식 라임, AI3: 사이버 바이올렛).
   - 모든 3D 모델 및 텍스처 Base64 완전 인라인 (별도 에셋 로드 없이 단일 파일 구동).

2. **150 ~ 250 km/h 속도 엔진 & 속도감 연출**
   - 일반 주행 150 km/h, N2O 부스터 250 km/h.
   - 카메라 FOV 왜곡 (60° $\to$ 98°), 150 km/h 이상 콕핏 럼블 진동, 4변 에어로 워프 비네트.
   - 중앙 시야 방해 없는 측면 유선형 에어로 윈드 스트림 60개.

3. **충돌 물리 & "쿵" Hit-Stop 타격감**
   - 벽/가드레일 및 카트 간 충돌 시 탄성 반발 + 속도 감쇠.
   - 충돌 순간 0.07~0.12초 물리 일시정지(Hit-Stop)로 묵직한 카트라이더 감속감 구현.
   - 화면 "💥 쿵!" 코믹 임팩트 팝업, 3D 충돌 스파크, WebAudio 합성 충돌음.

4. **실시간 타이어 스키드마크 (바큇자국)**
   - 드리프트, 부스터, 급제동 시 좌우 후륜 노면에 실시간 검은 고무 자국 생성 (`ShaderMaterial`).
   - 6.5초 후 자연스럽게 투명 페이드아웃 (메모리 누수 없는 정적 링 버퍼).

5. **지능형 레이싱 AI (전 기능 동등 탑재)**
   - 전방 4 웨이포인트 곡률 예측 -> 급커브에서 AI 드리프트 시전 및 게이지 충전.
   - 코너 탈출 즉시 순간 부스터(200 km/h) 연계.
   - 직선 주로에서 N2O 부스터(250 km/h) 점화 (3D 배기 화염 동시 분사).
   - 전방 카트 감지 시 레인 변경 추월 기동.

6. **3D 시상대 세레머니 (Podium Ceremony)**
   - 3랩 완주 시 3D 시상대 무대(1등 골드, 2등 실버, 3등 브론즈, 4등 바닥)로 카트 자동 배치.
   - 1등 카트 환호 바운스, 상공 회전 골드 트로피, 240개 오색 컨페티(꽃가루) 낙하.
   - 시네마틱 저각 회전 카메라, 승리 팡파르 합성음, 1~4등 기록판 UI, "다시 달리기" 지원.

## 🛠️ 기술 스택 (Tech Stack)

- **Three.js** (r160) - 3D 렌더링, 조명, 그림자, 커스텀 GLSL 셰이더
- **WebAudio API** - 실시간 프로그래머틱 엔진음, 타이어 스키드 노이즈, 충돌음, 승리 팡파르 합성
- **Pure Web Technologies** - HTML5, Canvas API, CSS3 애니메이션
